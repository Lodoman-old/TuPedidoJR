# Datos de códigos postales

`postal_codes_juventino_rosas.geojson` contiene los polígonos de códigos postales
del municipio de Santa Cruz de Juventino Rosas, Guanajuato.

Fuente: Servicio Postal Mexicano (SEPOMEX), datos abiertos publicados en
`datos.gob.mx`, procesados desde el repositorio
`open-mexico/mexico-geojson` (licencia MIT para el procesamiento; los datos
originales son de SEPOMEX).

Se usan únicamente para geocodificación inversa local en PostGIS
(`postal_code_areas`) y se cargan mediante la migración `030`.
