Configura tu menú

El menú es lo primero que ve el cliente. Mantén nombres claros, fotos cuadradas y precios actualizados.

1. Categorías

  1. Entra al panel del restaurante.
  2. Pulsa + Categoría.
  3. Escribe el nombre: Entradas, Pizzas, Bebidas, Postres, etc.

2. Platillos

  1. Pulsa + Platillo.
  2. Captura nombre, precio, descripción y categoría.
  3. Sube una foto. El sistema la recorta a 800×800 y la convierte a WebP.
  4. Activa o desactiva el platillo cuando se agote.
El precio que configuras es tu precio base. Al cliente se le muestra el precio con la comisión de plataforma incluida.

4. Opciones y modificadores

Puedes crear grupos para tamaño, extras, salsas o ingredientes.

TipoUso
Una opciónTamaño, término de la carne, tipo de bebida.
Varias opcionesExtras, salsas, ingredientes adicionales.
Ingredientes con precio máximoPizzas o platillos donde se elige hasta 4 ingredientes y se cobra el más caro.

En ingredientes con precio máximo, el sistema divide automáticamente en porciones iguales: 1/2, 1/3 o 1/4.

5. Disponibilidad e inventario

  • Marca Agotar cuando no tengas un producto.
  • Vuelve a activarlo cuando esté disponible.
  • Los clientes no pueden pedir productos agotados.

6. Horarios

  1. Abre Horario en el panel.
  2. Define los días y horas de atención.
  3. El sistema mostrará Abierto o Cerrado automáticamente.

7. Recoger en restaurante

Si el cliente puede pasar por el pedido:

  1. Entra a Editar negocio.
  2. Activa Permitir que el cliente recoja en el restaurante.
  3. El cliente elegirá entre envío o recoger.

Los pedidos para recoger no cobran envío ni propina. Se avisa al cliente cuando están listos.

8. Recomendaciones

  • Revisa precios y fotos cada semana.
  • No uses el mismo nombre para dos platillos distintos.
  • Describe claramente los ingredientes y alérgenos.
