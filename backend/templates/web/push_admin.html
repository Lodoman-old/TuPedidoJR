Se usa en el servidor para enviar por FCM HTTP v1. Se guarda en la base de datos y no se devuelve al navegador.
La usa la PWA (incluido iPhone) para obtener el token. Estos datos son públicos por diseño de Firebase.
Se usa en el APK para inicializar Firebase y obtener el token sin recompilar la app. Toma los valores de google-services.json de tu app Android.
Firebase Console → Configuración del proyecto → Cloud Messaging → Certificados push web.
1. Crear proyecto en Firebase

Entra a console.firebase.google.com y crea un proyecto.

2. Service account (privado)

Firebase Console → ⚙️ Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada.

Descarga el JSON y pégalo completo en el campo “Service account JSON”.

3. Configuración web (PWA / iPhone)

Firebase Console → ⚙️ Configuración del proyecto → Tus apps → agrega una app web.

Copia el objeto firebaseConfig y pégalo en “Configuración web”.

4. VAPID key

Firebase Console → Cloud Messaging → Certificados push web → genera un par de claves.

Copia la clave pública (empieza con “B”) en el campo VAPID key.

5. APK Android

En Firebase Console agrega una app Android con el paquete com.tupedidojr.tupedidojr y descarga google-services.json.

De ese archivo toma estos valores y pégalos en “Configuración Android”:

{
  "project_id": "tupedidojr",
  "mobilesdk_app_id": "1:...:android:...",
  "api_key": "AIza...",
  "gcm_defaultSenderId": "..."
}

El APK los descarga al iniciar y obtiene su token FCM sin necesidad de recompilar. Luego lo registra en /api/v1/push/tokens.
